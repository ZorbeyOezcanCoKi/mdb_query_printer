# Query Printer

Pipeline, die aus drei Rohdatenquellen (MdB-Adresspaket, DBoeS-Datenbank, Stiftungen-Liste)
Social-Media-Handles extrahiert und daraus [Brandwatch](https://www.brandwatch.com/products/consumer-research/)-Queries
für Social-Media-Monitoring generiert.
